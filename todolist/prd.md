# Todo List 웹사이트 PRD

## 1. 제품 개요

- **제품명:** Todo List
- **목표:** 사용자가 할 일을 빠르게 등록하고, 진행 상태를 관리하며, 완료한 항목을 확인할 수 있는 가벼운 웹사이트를 제공한다.
- **대상 사용자:** 개인 할 일을 간단히 정리하고 싶은 사용자
- **플랫폼:** 데스크톱 및 모바일 웹 브라우저

## 2. 문제 정의

사용자는 해야 할 일을 기록하고 완료 여부를 한눈에 파악할 수 있어야 한다. 복잡한 가입이나 서버 설정 없이 브라우저에서 바로 사용할 수 있는 간단한 도구가 필요하다.

## 3. 목표 및 범위

### 목표

- 할 일 추가, 완료 처리, 수정, 삭제를 지원한다.
- 전체·미완료·완료 상태별로 할 일을 확인할 수 있다.
- 브라우저를 닫았다가 다시 열어도 할 일 데이터가 유지된다.
- 모바일과 데스크톱에서 읽고 조작하기 쉬운 화면을 제공한다.

### MVP 범위

- 단일 목록의 할 일 관리
- 할 일 제목 입력 및 유효성 검사
- 완료 상태 전환
- 할 일 제목 수정 및 항목 삭제
- 상태 필터(전체, 미완료, 완료)
- 현재 목록의 항목 수 및 완료 수 표시
- `localStorage`를 이용한 브라우저 내 데이터 저장
- 반응형 레이아웃과 기본 키보드 접근성

### 범위 제외

- 사용자 계정, 로그인, 서버 동기화
- 여러 목록, 태그, 우선순위, 마감일, 알림
- 협업 및 공유
- 백엔드 API 및 데이터베이스

## 4. 사용자 시나리오

1. 사용자는 페이지를 열고 입력란에 할 일을 입력한 뒤 추가한다.
2. 사용자는 항목의 완료 컨트롤을 눌러 진행 상태를 변경한다.
3. 사용자는 완료 상태별 필터를 선택해 필요한 항목만 확인한다.
4. 사용자는 기존 항목의 제목을 수정하거나 불필요한 항목을 삭제한다.
5. 사용자는 페이지를 다시 열어 이전에 저장한 목록을 확인한다.

## 5. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-01 | 비어 있거나 공백뿐인 제목은 추가하지 않고 사용자에게 입력을 안내한다. | 필수 |
| FR-02 | 유효한 제목을 입력하면 새 미완료 항목을 목록에 추가한다. | 필수 |
| FR-03 | 항목별 완료 여부를 전환할 수 있다. | 필수 |
| FR-04 | 항목 제목을 수정하고 저장하거나 취소할 수 있다. | 필수 |
| FR-05 | 항목을 삭제할 수 있다. | 필수 |
| FR-06 | 전체, 미완료, 완료 필터로 목록을 전환할 수 있다. | 필수 |
| FR-07 | 전체 항목 수와 완료 항목 수를 표시한다. | 권장 |
| FR-08 | 목록 변경 사항을 브라우저 저장소에 반영하고 다음 방문 시 복원한다. | 필수 |
| FR-09 | 표시할 항목이 없을 때 적절한 빈 상태 안내를 제공한다. | 권장 |

## 6. 비기능 요구사항

- 별도 설치나 빌드 도구 없이 최신 브라우저에서 실행할 수 있어야 한다.
- 화면은 작은 모바일 폭부터 데스크톱까지 가로 넘침 없이 사용할 수 있어야 한다.
- 주요 입력과 버튼은 키보드로 조작할 수 있고 명확한 포커스 표시가 있어야 한다.
- 상태는 색상만으로 구분하지 않으며 텍스트 또는 의미 있는 컨트롤을 함께 제공한다.
- 사용자 데이터는 기본적으로 현재 브라우저에만 저장하며 서버로 전송하지 않는다.

## 7. UX 및 수용 기준

- 처음 방문하면 할 일 입력과 빈 목록 안내를 볼 수 있다.
- 공백 제목을 제출해도 항목이 생성되지 않는다.
- 새 항목을 추가하면 목록과 항목 수가 즉시 갱신된다.
- 완료 상태를 바꾸면 완료 스타일, 필터 결과, 완료 수가 함께 갱신된다.
- 수정 및 삭제 결과는 새로고침 후에도 유지된다.
- 각 필터는 해당 상태의 항목만 표시하며 전체 필터는 모든 항목을 표시한다.
- 저장된 데이터가 없을 때 오류 없이 빈 목록으로 시작한다.

## 8. 성공 기준

- 핵심 CRUD 및 필터 시나리오를 브라우저에서 모두 수행할 수 있다.
- 새로고침 후 저장된 목록과 완료 상태가 복원된다.
- 모바일과 데스크톱에서 주요 기능을 모두 사용할 수 있다.
